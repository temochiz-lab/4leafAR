# 4leafAR

四葉のクローバーを探すARのWeb版プロトタイプです。スマートフォンの背面カメラ、または選択した画像を解析し、四葉らしい候補をCanvas上に重ねて表示します。

## Pages

https://temochiz-lab.github.io/4leafAR/

## 機能

- `getUserMedia` による背面カメラ起動
- Canvas 2Dによるカメラ/画像プレビューと候補マーカー表示
- 緑色領域、葉らしい輪郭、放射配置にもとづくルールベース候補スコア
- 追跡IDと連続検出によるマーカー安定化
- 候補タップ後のラベル付け
- IndexedDBへの候補クロップ画像とメタデータ保存
- JSONと候補画像のダウンロード
- 判定しきい値、解析頻度、デバッグ表示の調整

## 使い方

1. HTTPSで公開されたPages URLをスマートフォンで開きます。
2. `カメラ開始` を押して、カメラ権限を許可します。
3. クローバーの群生を30-50cm程度の距離から、できるだけ真上に近い角度でゆっくり映します。
4. 候補マーカーをタップし、必要に応じて `四葉` / `三葉` / `判定不能` / `誤検出` のラベルを付けて保存します。
5. `JSON保存` または `候補画像保存` で収集データを書き出します。

PCで試す場合は `画像選択` からクローバー画像を読み込めます。

## ローカル起動

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4173/` を開きます。

## 注意

このプロトタイプは四葉を100%断定するものではありません。大量の三葉から、人間が確認すべき候補を絞り込むための初期版です。クローバーが密集している場合、葉の重なり、風、強い影、斜め撮影では誤検出や見逃しが増えます。

映像や画像はサーバーへ送信せず、ブラウザ内で解析します。保存した候補画像とJSONも端末内のIndexedDBに保持され、ユーザー操作でダウンロードできます。

## 構成

```text
index.html
css/app.css
js/camera.js
js/detector.js
js/tracker.js
js/overlay.js
js/storage.js
js/app.js
```

将来、`js/detector.js` をOpenCV.jsやONNX Runtime Webの検出器に差し替えられるよう、カメラ、検出、追跡、描画、保存の責務を分けています。
